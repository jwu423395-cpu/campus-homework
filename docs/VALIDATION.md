## 真实学习通闭环

经用户授权，在实际 Windows 学习通普通作业中验证了一道要求横向拍照上传的过程题，
对应用户提供的两张练习册原页、12个小问。实际完成：

1. 从课程作业通知定位，核对课程、作业名、期限、题量和横向图片要求。
2. 从原页读取矩阵，独立推导并用精确计算复核；检查矩阵维度、负号、转置、乘法顺序及分数。
3. 按用户参考调整模拟手写外观，只将核验后的答案笔迹合成回原页空白区，恢复印刷保护区。
4. 用短英文名上传两张2270×1276的 JPG，检查完整预览、页序与内容。
5. 点击保存，关闭作答标签，从原任务入口重新打开，确认两页均持久化、顺序正确。
6. 通过日志提交门槛后正常确认提交，实际页面显示“提交成功”“等待教师批阅”，时间为
   2026-10-25 14:30；日志状态为 `submitted`、分数为 `null`。

没有评分证据，不声称满分。真实题照、截图、姓名、课程任务记录及笔迹参考未进入公开文件。
这次只验证了该客户端的图片过程题；真实平台的全部客观题控件、模拟考试、网络中断恢复
和所有上传异常仍未逐项实测。本地样例覆盖的逻辑不能代替这些平台兼容性验证。

过程中记录了三类低效操作：上传后布局异步变化、光标位置导致页序颠倒、切回聊天窗口后
输入保护停止。技能已要求先确认编辑区和插入位置，等待布局稳定后重新观察，按页序上传并
读回；不按旧坐标连续点击，不把代码块按钮当作HTML源码，不持续争抢焦点。

## 本地保存的 Windows 错误17

真实偏好保存时，在本机 EFS 加密的应用数据目录，同目录且设备号相同的 `os.replace`
仍返回 Windows 错误17。没有足够证据将根因归于EFS，未修改系统加密设置。

偏好与运行日志共用 `fileio.py`：优先原子替换，仅错误17触发明确警告的非原子回退；先
同步完整内容及旧值备份，写目标后读回，失败恢复旧值，恢复也失败则保留完整备份并报位置。
首次创建为独占创建，其他错误不自动降级。正常文件系统仍使用原子替换。

在实际目录用独立探测文件验证偏好首次创建/更新及日志创建/更新/读回，均成功且输出回退
警告，探测文件已清理。测试覆盖部分写入后旧值恢复、恢复失败备份保留。该回退不提供
崩溃原子性或并发读写支持，仍须单写入者。

## 字体、素材与发行隐私

三套固定字体的原始SHA、来源和OFL已核对。文楷、悠哉分别覆盖GB2312的6763个汉字，
辰宇覆盖4333个，缺字逐字回退文楷并记录，仍缺则报错；不承诺覆盖全部中文。辰宇无效
TrueType hint 只在内存副本移除，原文件不变，调整写入渲染清单。

12种字体/纸张样张和拟真样张已生成查看。桌面背景明确标记AI生成，图片称模拟手写/
拟真合成，不声称实拍。用户笔迹参考仅私有使用，不分发水印、他人题目或签名。

发行脚本只允许明确公开目录，排除环境、缓存、账号、日志、私人题照及运行数据，扫描
个人路径和高置信凭据，核对字体SHA、许可证及自编题单来源；ZIP逐成员回读校验并生成
SHA256清单。测试归档曾两次产生相同SHA；正式发行须以最终归档清单和哈希为准。

## 仍由 Codex 与用户环境配合的部分

- Codex完整读题、推导、复核、判断编辑框及提交状态；脚本不自动识别全部课程和题型。
- 登录、扫码、验证码由用户完成。真实控件和页面变化须重新观察，输入保护不能理解题号。
- 原页填写区/保护区由 Codex 观察给定，没有验证严重反光、缺页或自动矫正所有对开页。
- 内置图像工具由当前宿主提供；缺失时用准确模式，不猜测API密钥或宣称图像服务可用。
- 首版支持范围不等于各功能在所有平台版本均完成实测，以上实际验证范围优先。
